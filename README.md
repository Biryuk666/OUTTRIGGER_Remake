## О проекте

**OUTTRIGGER Remake** — фанатский проект, цель которого — воссоздать динамику и основные игровые механики OUTTRIGGER средствами Unreal Engine 5.

Сейчас в проекте реализуется базовый игровой цикл: перемещение по арене, стрельба, переключение оружия, получение урона, подбор ресурсов и отображение состояния игрока через HUD.

## Реализовано

- персонаж с видом от третьего лица и возможностью переключения камеры;
- модульные компоненты здоровья и оружия;
- hitscan- и projectile-оружие;
- базовые классы для винтовки, гранатомёта, ракет и гранат;
- слоты оружия и раздельные пулы боеприпасов;
- подбор здоровья, брони, патронов и усиления Eagle;
- система урона, смерти и точек появления;
- aim assist с визуальным откликом прицела;
- HUD со здоровьем, боеприпасами, слотами оружия и прицелом;
- визуальные уведомления о получении урона, лечении и малом количестве ресурсов;
- ввод через Enhanced Input, включая перемещение, обзор и прыжок с геймпада;
- прототип игровой арены.

## Управление

| Действие | Клавиатура и мышь |
| Перемещение | `W` `A` `S` `D` |
| Обзор | Мышь |
| Прыжок | `Space` |
| Огонь | Левая кнопка мыши |
| Следующее оружие | Колесо мыши вверх |
| Предыдущее оружие | Колесо мыши вниз |
| Переключить вид | `V` |

## Запуск проекта

### Требования

- Unreal Engine **5.8**;
- Git;
- [Git LFS](https://git-lfs.com/);
- Windows 10/11;
- видеокарта с поддержкой DirectX 12 — рекомендуется, поскольку в проекте включены Lumen и аппаратный Ray Tracing.

### Установка

1. Клонируйте репозиторий:

   ```bash
   git clone git@github.com:Biryuk666/OUTTRIGGER-Remake.git
   cd OUTTRIGGER-Remake
   ```

2. Загрузите файлы Git LFS:

   ```bash
   git lfs install
   git lfs pull
   ```

3. Откройте `OUTTRIGGER.uproject` в Unreal Engine 5.8.

4. Дождитесь подготовки шейдеров, затем откройте карту:

   ```text
   Content/OUTTRIGGER/Maps/ThirdPersonMap
   ```

5. Нажмите **Play** в редакторе.

> [!NOTE]
> Папки `Binaries`, `Intermediate`, `DerivedDataCache` и `Saved` не хранятся в репозитории и будут созданы Unreal Engine автоматически.
